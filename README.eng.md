## RUS

С помощью этого скрипта IMDB, TMDB, Kinopoisk и Letterboxd станут бесплатными онлайн-кинотеатрами! На каждой странице с фильмом или сериалом в левом верхнем углу появится флажок. Нажав на него, вы откроете плеер с фильмом.

## ENG

With this script, IMDB, TMDB, Kinopoisk and Letterboxd will become free online cinemas! On each page with a movie or TV series, a flag will appear in the upper left corner. By clicking on it, you will open a player with the movie.

## Important

Due to RKN blocks and general internet instability on Russian territory, a VPN is REQUIRED for the script to work. I cannot guarantee the stability of the service for users located in the RF.

## Installation 🎓

Install one of the user script runner extensions:

- **Tampermonkey** (recommended)
- **Violentmonkey**
- **Greasemonkey**
- **Userscripts**

Enable script execution and developer mode in your browser.

Install the script by following this link. (or download tape-operator.user.js from the userscript folder and install manually)

Done, now open a movie page on one of the supported sites (example) and click on the flag in the upper left corner!

If the flag doesn't appear, check that the script is installed correctly and restart your browser.
